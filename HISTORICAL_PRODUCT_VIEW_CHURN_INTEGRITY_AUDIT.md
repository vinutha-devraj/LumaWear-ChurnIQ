## 2. Root Cause of the Anomaly

The 38,140 records were generated by a **React `useEffect` dependency loop** in `ProductDetailsPage.jsx`:
1. `ProductDetailsPage` mounted when browsing product `lw-008`.
2. An unmemoized `addRecentlyViewed` callback in `StoreContext` dispatched an action updating `state.recentlyViewed` and logged an activity event via `POST /api/activity`.
3. The state change caused `StoreProvider` to re-render, creating a new inline reference for `addRecentlyViewed`.
4. `ProductDetailsPage` re-rendered, saw the new function reference in its `useEffect` dependency array `[product, addRecentlyViewed]`, and re-executed the effect.
5. This loop fired ~65.13 HTTP requests per second for 9.76 minutes until the page was closed or navigated away.

## 9. Data-Cleaning Recommendation

### Recommended Choice: **OPTION 3 — Archive / Clean the Anomalous Loop Burst**

**Rationale:**
While the records will naturally age out on September 25, 2026 without causing a risk tier change, retaining 38,140 duplicate records creates a cosmetic recommendation artifact (`"Customer browsed 38140 products..."`) and inflates database telemetry size.

**Safe Targeted Query (RECOMMENDATION ONLY — NOT EXECUTED):**
The proposed query safely preserves **1 legitimate product view** for that browsing session and deletes only the rapid loop duplicates:

```javascript
// TARGETED CLEANUP SCRIPT (RECOMMENDED ONLY - DO NOT RUN AUTOMATICALLY)
import mongoose from "mongoose";

const targetUserId = new mongoose.Types.ObjectId("6a8e91d0757ba1c728e8caaf");
const windowStart = new Date("2026-08-26T07:12:36.000Z");
const windowEnd   = new Date("2026-08-26T07:22:22.000Z");

// Step 1: Find the first event to preserve it
const firstEvent = await db.collection("activities").findOne({
  userId: targetUserId,
  type: "product_viewed",
  "metadata.productId": "lw-008",
  createdAt: { $gte: windowStart, $lte: windowEnd },
}, { sort: { createdAt: 1 } });

// Step 2: Delete only subsequent duplicates generated by the loop
if (firstEvent) {
  const result = await db.collection("activities").deleteMany({
    userId: targetUserId,
    type: "product_viewed",
    "metadata.productId": "lw-008",
    createdAt: { $gt: firstEvent.createdAt, $lte: windowEnd },
  });
  console.log(`Safely removed ${result.deletedCount} loop duplicates. 1 legitimate view preserved.`);
}
```
